# 🌌 Cosmic Hub & Space Apps Portal

A modern, serene, deep-space dashboard (`Deep Space Black`) featuring interactive canvas stars, meteors, and a refined **Apps & Software Dock** with full admin control.

---

## ✨ Key Features

1. **Cosmic Apps & Software Dock:**
   - Dedicated glassmorphism dock for your essential programs and web tools (Photoshop, Telegram, ChatGPT, VS Code, Discord, YouTube, GitHub, Figma, etc.).
   - Clean glowing icon cards with subtle levitation and neon hover halos.
   - Distinct, elegant typography powered by Google Fonts (`Outfit` & `Plus Jakarta Sans`).

2. **Clean & Minimalist Interface:**
   - Removed all unnecessary clutter, search bars, and category filters for a tranquil, focused experience.
   - The 4 large default placeholder boxes have been completely removed.
   - Built with native LTR layout and English language throughout.

3. **Full Admin Dashboard (PIN-Protected):**
   - Floating action button at the bottom for quick access.
   - Security PIN protection (**PIN:** `2007`).
   - **Apps & Software Management:** Add new apps, edit existing names/URLs/icons, reorder (Move Up/Down), or delete.
   - **Website Links:** Optionally add custom website cards whenever needed.
   - **Profile Customization:** Modify display name, tagline/bio, avatar image, and PIN.
   - **Backup & Restore:** Download or import your entire configuration as a single `.json` file.

---

## 🚀 How to Run:
1. Open `index.html` in any web browser.
2. Click the **"Admin Panel"** button in the bottom corner and enter PIN `2007` to customize your apps and profile!
